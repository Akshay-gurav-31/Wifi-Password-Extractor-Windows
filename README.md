# Wifi-Password-Extractor-Windows

A simple and efficient Python script to extract and display saved Wi-Fi passwords from a Windows machine using the native `netsh` utility.

## 🚀 Features
- 🛡️ **Secure Search**: Specifically filters for networks with saved passwords (ignores open/unsecured networks).
- 📊 **Clean Output**: Displays results in a professional, easy-to-read tabular format.
- 🔤 **Sorted Results**: Automatically sorts networks alphabetically for better organization.
- 💻 **Windows Optimized**: Uses native Windows `netsh` commands for zero external dependencies.

## 📋 Prerequisites
- **Python 3.x**
- **Windows OS**

## 🛠️ Usage
1. Clone the repository:
   ```bash
   git clone https://github.com/Akshay-gurav-31/Wifi-Password-Extractor-Windows.git
   ```

2. Navigate to the directory:
   ```bash
   cd Wifi-Password-Extractor-Windows
   ```
3. Run the script:
   ```bash
   python wifi_extractor.py
   ```
